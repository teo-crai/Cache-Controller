This project implements and tests a cache controller for a simple computer system using Verilog and ModelSim.
The cache controller is built around a finite state machine (FSM) to manage the operations and state transitions effectively.
Cache specs:
-Cache Type: 4-way set associative
-Cache Size: 32 KB
-Block Size: 64 bytes
-Word Size: 4  bytes
-Number of Sets: 128 sets
-Associativity Level: 4-way
-Replacement Policy: Least Recently Used (LRU)
-Write Policy: Write back with write allocate
